# UI 第二轮优化设计文档

**日期：** 2026-04-07
**状态：** 已批准

---

## 概述

对 Dreamina 视频生成 Web UI 进行第二轮优化，涵盖三个方向：整体布局重构、任务列表筛选、提示词媒体文件 `@` 引用。

---

## 1. 整体布局重构

### 目标

将当前多页面（提交任务 / 任务列表 独立页面切换）改为**单页左右分栏**布局，用户无需切换页面即可同时看到表单和任务状态。

### 布局结构

```
┌─────────────────────────────────────────────────┐
│  Header: 应用标题 | 账号选择器+余额 | 账号管理    │
├──────────────────┬──────────────────────────────┤
│  左侧 (42%)      │  右侧 (58%)                   │
│  提交任务表单    │  任务列表（可滚动）            │
│  （固定，不滚动）│  筛选器 + 任务卡片             │
└──────────────────┴──────────────────────────────┘
```

### Header 变化

- 深色顶栏（`#1e1e2e`）
- 去掉顶部导航菜单（提交/任务列表不再是独立路由页面）
- 账号选择器移至右侧，显示在线状态圆点 + 余额
- 保留"账号管理"文字链接

### 左侧表单面板

- 宽度约 42%，内容固定不随整体滚动
- 媒体上传区：图片 / 音频 / 视频三个按钮集中在一个上传区域内
- 提示词输入框（支持 `@` 引用，见第 3 节）
- 参数行：时长滑块、比例下拉、模型下拉，横向排列
- 提交按钮

### 右侧任务列表面板

- 背景色 `#f5f7fa`，内容可垂直滚动
- 顶部固定筛选栏（见第 2 节）
- 任务卡片：左侧 3px 彩色状态条（绿/橙/红/灰）
- 自动轮询刷新（保持现有 10s 间隔）

### 文件变更

| 文件 | 改动 |
|------|------|
| `frontend/src/App.vue` | 重构为左右分栏布局，移除路由导航菜单 |
| `frontend/src/views/SubmitTask.vue` | 去掉外层 card 包装，适配左侧面板宽度 |
| `frontend/src/views/TaskList.vue` | 嵌入右侧面板，添加筛选器 |
| `frontend/src/router/index.js` | 保留路由但主页面直接渲染两个面板组件 |

## 2. 任务列表筛选

### 筛选条件

| 筛选项 | 组件类型 | 选项 |
|--------|----------|------|
| 状态 | Tag 按钮组（单选） | 全部 / 等待中 / 生成中 / 已完成 / 失败 |
| 账号 | 下拉选择框 | 全部 + 各账号 ID（动态从 `api.listAccounts()` 获取） |

### 交互

- 状态和账号筛选相互独立，可组合使用
- 切换筛选条件立即触发 `fetchTasks({ status, account_id })`
- 后端 `GET /api/tasks` 已支持 `status` 和 `account_id` 查询参数，**无需修改后端**

### 筛选器位置

任务列表面板顶部固定栏，与"任务列表"标题和刷新按钮同行。

## 3. 提示词 `@` 媒体文件引用

### 功能描述

用户在提示词 textarea 中输入 `@` 时，弹出浮层列出已上传的媒体文件供选择，选中后自动在光标处插入 `@图片1`、`@音频1`、`@视频1` 等标记。

### 文件列表来源

从表单当前上传状态读取（不调用后端）：
- `form.images` → `@图片1`, `@图片2`, ...
- `form.audios` → `@音频1`, `@音频2`, ...
- `form.videos` → `@视频1`, `@视频2`, ...

### 浮层交互

1. 监听 textarea 的 `input` 事件，检测最后输入字符是否为 `@`
2. 若触发，在光标位置附近弹出选择浮层
3. 浮层分组展示：「图片」「音频」「视频」，每项显示序号名称和原始文件名
4. 点击选项，将 `@图片1` 等标记插入光标位置，关闭浮层
5. 按 `Esc` 或点击其他区域关闭浮层
6. 若无任何已上传文件，不弹出浮层（可选：给出提示"请先上传文件"）

### 标记含义

`@图片1` 等标记为**纯文本**，原样包含在最终提交给 Dreamina 的 `prompt` 字段中，后端不做特殊解析。

### 实现方式

使用 Vue 3 自定义逻辑（非第三方库）：
- `@` 触发检测：监听 `@input` 事件
- 浮层定位：`position: absolute`，相对 textarea 容器定位
- 光标插入：`textarea.setSelectionRange` + 字符串拼接
