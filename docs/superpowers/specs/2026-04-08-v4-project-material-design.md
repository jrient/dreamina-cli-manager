# V4 版本设计：项目与素材管理系统

## 概述

V4 版本引入项目和素材管理功能，重构任务创建流程的媒体引用机制，并整合 Admin 管理界面。

**核心变更**：
- 项目模块：任务的分类管理容器
- 素材模块：项目级别的媒体资源库
- 任务改造：关联项目 + 标签字段 + 复制功能
- @素材引用：缩略图占位符机制，统一引用体验
- Admin 界面：项目管理 + 账号配置 + 全局任务列表

## 1. 数据模型

### 1.1 新增表：projects

```sql
CREATE TABLE projects (
    id          TEXT PRIMARY KEY,
    name        TEXT NOT NULL,
    deleted_at  TEXT,              -- NULL 表示活跃，有值表示软删除
    created_at  TEXT NOT NULL,
    updated_at  TEXT NOT NULL
);
```

**设计说明**：
- 项目全局共享，不关联账号
- 软删除通过 `deleted_at` 字段实现
- 状态仅有活跃/已删除两种

### 1.2 新增表：materials

```sql
CREATE TABLE materials (
    id          TEXT PRIMARY KEY,
    project_id  TEXT NOT NULL,
    name        TEXT NOT NULL,     -- 用户命名
    type        TEXT NOT NULL,     -- 'image' / 'audio'
    file_path   TEXT NOT NULL,     -- 存储路径
    created_at  TEXT NOT NULL,
    FOREIGN KEY (project_id) REFERENCES projects(id)
);
```

**设计说明**：
- 素材全局共享，挂载在项目下
- 文件存储：`uploads/materials/<material_id>.<ext>`

### 1.3 修改表：tasks

```sql
-- 新增字段
ALTER TABLE tasks ADD COLUMN project_id TEXT;  -- 可为 NULL，关联项目
ALTER TABLE tasks ADD COLUMN label TEXT;       -- 标签，最多 50 字符，仅显示不参与 CLI
```

**设计说明**：
- 任务仍关联 `account_id`，项目仅为分类
- 标签可选，长度限制 50 字符

### 1.4 ER 关系图

```
projects (全局)
    │
    ├── materials (素材，按项目组织)
    │       │
    │       ├── image 类型
    │       └── audio 类型
    │
    └── tasks (任务，可选关联)
            │
            └── account_id (账号关联，保持不变)
```

## 5. @素材引用机制（核心改造）

### 5.1 新的提示框交互

**输入 `@` 时弹出列表**：
- 项目素材 + 已上传文件（合并显示）
- 分组显示：素材区（上方）+ 已上传区（下方）

**选择后的显示**：
- 内联显示缩略图占位符（大小与文字相近）
- 不显示文字 `@图片1`

### 5.2 素材引用逻辑

```
用户操作流程示例：

1. 用户在提示框输入 "这是一张"
2. 输入 @ → 弹出选择列表
3. 选择素材 "素材图1"
4. 系统行为：
   - 素材文件加入上传框末尾（假设位置为图片3）
   - 提示框显示：这是一张[缩略图]
   - 记录映射：素材图1 → 图片3

5. 继续输入 "，我喜欢它"
6. 再次输入 @ 选择同一素材
7. 系统行为：
   - 不重复添加到上传框
   - 提示框显示：这是一张[缩略图]，我喜欢[缩略图]

8. 提交任务
9. 替换逻辑：
   - 扫描所有缩略图引用
   - 按上传框位置替换为 @图片N/@音频N/@视频N
   - 最终 CLI 提示词：这是一张@图片3，我喜欢@图片3
```

### 5.3 映射规则

| 场景 | 行为 |
|------|------|
| 首次引用素材 | 素材文件追加到上传框末尾，记录映射 |
| 再次引用同一素材 | 不重复添加，复用已有映射 |
| 删除上传框文件 | 实时更新显示，缩略图位置动态调整 |
| 提交任务 | 统一替换为 @图片N/@音频N/@视频N |

### 5.4 统一处理

手动上传文件 + 素材引用统一用缩略图占位符显示：
- 手动上传的文件也显示为缩略图
- 素材引用显示为缩略图（带素材标识）
- 提交时统一替换

## 7. 实现优先级

按依赖关系顺序实现：

| 序号 | 子系统 | 依赖 |
|------|--------|------|
| 1 | 项目模块 | 无依赖，基础模块 |
| 2 | 素材模块 | 依赖项目 |
| 3 | 任务改造 | 依赖项目 |
| 4 | @素材引用 | 依赖素材 + 任务改造 |
| 5 | 复制任务功能 | 依赖任务改造 + 素材引用 |
| 6 | Admin 界面 | 依赖所有模块 |
